# Estudos e projetos de Power BI

Repositório de estudos da formação Power BI Analyst da DIO. Os materiais das aulas permanecem nas pastas originais e as entregas estão organizadas em `desafios`.

## Projeto em destaque

### Relatório de vendas

Relatório de três páginas com a amostra didática Financial Sample, abordando vendas, unidades vendidas, lucro por país e lucro por segmento.

A entrega documenta as adaptações do relatório de referência, as configurações dos visuais e as evidências de publicação. O material original não é apresentado como criação integral do autor.

[**Abrir projeto, arquivo PBIX e evidências**](desafios/relatorio-vendas/README.md)

## Como avaliar

1. Leia o README do desafio para conhecer o objetivo, a origem dos dados e o que foi adaptado.
2. Confira as imagens das páginas do relatório.
3. Baixe o PBIX e abra no Power BI Desktop para explorar os visuais.

O link do Power BI Service pode exigir autenticação e permissão. As evidências no repositório permitem consultar a apresentação sem depender desse acesso.

## Competências praticadas

- Configuração de campos e agregações nos visuais.
- Comparação de vendas, unidades e lucro.
- Análise visual por país e segmento.
- Títulos em português, dicas de ferramentas e documentação do projeto.

Os dados são de uma amostra educacional.
